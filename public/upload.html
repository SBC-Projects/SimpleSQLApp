Instructions

  1. Drop a .xlsx file into the upload box.
  2. Check the table name, column names, data types, required fields, and primary key.
  3. Copy the CREATE TABLE SQL into your assignment if you need to show your schema.
  4. Click Create table to add the empty table to SQLite.
  5. Click Import rows to fill the table with the Excel data.
